1. Présentation

Cette application affiche une vidéo sur des barres de LEDs pilotées par un contrôleur WLED (par exemple le Gledopto GL-C-618WL). Elle fonctionne avec un fichier vidéo ou avec n'importe quel onglet ou fenêtre de l'ordinateur, comme une vidéo YouTube.

Les couleurs sont envoyées en Art-Net par le câble Ethernet (RJ45), environ 30 fois par seconde.

Vidéo ─► Page web (calcule la couleur de chaque LED) ─► Relais Python (lancer.bat) ─► câble RJ45, Art-Net ─► Boîtier WLED ─► LEDs

Pourquoi un relais ? Un navigateur web ne peut pas envoyer d'Art-Net, qui passe par des paquets UDP. Le petit programme Python fait ce relais. Il n'a besoin d'aucun module supplémentaire.

2. Matériel nécessaire

  • Un ordinateur Windows avec une prise Ethernet (ou un adaptateur USB-Ethernet).
  • Un contrôleur WLED avec Ethernet (Gledopto série « Ethernet »).
  • Des barres ou rubans de LEDs adressables (WS2812B, WS2815, SK6812…).
  • Une alimentation adaptée au nombre de LEDs (voir §12).
  • Un câble RJ45 entre l'ordinateur et le boîtier.
  • Google Chrome ou Microsoft Edge.

3. Installation (une seule fois)

  1. Télécharge Python sur python.org/downloads et installe-le.
    Pendant l'installation, coche bien la case « Add python.exe to PATH ».
  2. Copie le dossier artnet-video où tu veux sur l'ordinateur. Il contient index.html, artnet_bridge.py et lancer.bat.

4. Réseau Ethernet

Si le boîtier est branché directement sur l'ordinateur, sans box ni switch, personne ne distribue les adresses IP. Il faut donc des adresses fixes :

AppareilAdresse IPMasque
Boîtier WLED192.168.50.2255.255.255.0
Ordinateur (carte Ethernet)192.168.50.1255.255.255.0

Sur Windows

Paramètres → Réseau et Internet → Ethernet → Attribution d'adresse IP → Modifier → Manuel → IPv4 activé : adresse 192.168.50.1, masque 255.255.255.0. Laisse la passerelle et le DNS vides.

Dans WLED

Connecte-toi d'abord au boîtier par son Wi-Fi, puis :

  1. Config → WiFi Setup → Ethernet Type : Gledopto Series With Ethernet. Enregistre, puis redémarre le boîtier.
  2. Config → WiFi Setup → Static IP : 192.168.50.2, Subnet : 255.255.255.0.
  3. Avec le câble branché, l'adresse http://192.168.50.2 doit s'ouvrir depuis l'ordinateur.

Si le pare-feu Windows le demande au premier lancement, autorise Python sur les réseaux privés.

Pourquoi désactiver la 2D ? C'est l'application qui connaît la position de chaque LED. Elle envoie les couleurs directement dans l'ordre du fil. Si la 2D restait active, WLED remettrait les LEDs dans un autre ordre une seconde fois.

Les univers. Un univers Art-Net transporte 170 LEDs RGB au maximum. L'application découpe les données automatiquement. Par exemple, 600 LEDs = 4 univers (1 à 4). Le nombre d'univers utilisés s'affiche dans le bloc « WLED / Art-Net ».

6. Lancer l'application

  1. Double-clique sur lancer.bat. Une fenêtre noire s'ouvre : c'est le relais, laisse-la ouverte.
  2. Le navigateur s'ouvre sur http://localhost:8080. Si ce n'est pas le cas, ouvre cette adresse à la main.
  3. En haut à droite, « Relais : connecté » confirme que la page communique avec le relais.
  4. Dans « WLED / Art-Net », vérifie l'IP du WLED et l'univers de départ.

Pour arrêter : bouton « ⏹ Arrêter » (les LEDs s'éteignent), puis ferme la fenêtre noire.

7. Décrire l'installation

L'application doit savoir où se trouve chaque barre pour que chaque LED prenne la couleur de la vidéo à son emplacement réel. Les barres peuvent être horizontales, verticales, espacées différemment ou en biais.

Chaque barre est décrite par :

  • un point de début : le côté par où arrive le fil de données (● dans l'éditeur) ;
  • un point de fin (■ dans l'éditeur) ;
  • un nombre de LEDs, réparties régulièrement entre ces deux points.

Les positions sont en centimètres, vues de face : X vers la droite, Y vers le haut. L'ordre des barres dans le tableau est l'ordre du fil : la barre 1 reçoit les premières LEDs, la barre 2 les suivantes, etc.

a) Le générateur (le plus rapide)

Bloc « Créer une disposition » : indique le nombre de barres, leur longueur, le nombre de LEDs par barre, l'espacement réel entre deux barres, l'orientation, le coin par où le fil arrive et si le câblage fait des allers-retours (serpentin). Clique ensuite sur « Générer ».

Exemple : 5 barres horizontales de 2 m, 120 LEDs chacune, espacées de 50 cm, fil qui arrive en bas à droite et serpente jusqu'en haut à gauche.

b) L'éditeur à la souris

  • Fais glisser le ● ou le ■ d'une barre pour déplacer une extrémité.
  • Fais glisser le milieu d'une barre pour la déplacer entière.
  • Les déplacements se font par paliers (10 cm, 25 cm, 50 cm ou 1 m, au choix en haut de l'éditeur). Maintiens Alt pour un placement libre.
  • La flèche au milieu de chaque barre indique le sens du fil.
  • Le cadre bleu en pointillés est la « scène » : la zone cadrée dans la vidéo. Elle s'ajuste automatiquement aux barres.

c) Le tableau (saisie précise)

  • Tape les coordonnées en cm et le nombre de LEDs.
  • La colonne « N° LEDs » indique quelles LEDs du fil correspondent à chaque barre.
  • ▲ ▼ changent l'ordre de la barre dans la chaîne, ⇄ inverse son sens, ✕ la supprime, « ＋ Ajouter une barre » en crée une nouvelle.

8. Vérifier avec la mire

Avant de lancer une vidéo, clique sur Mire dans le bloc « Tests ». Chaque barre s'allume dans la couleur de sa pastille du tableau, en dégradé du début (sombre) vers la fin (claire).

Ce que tu voisCorrection
Une barre n'a pas la bonne couleurL'ordre est faux : corrige-le avec ▲ ▼
Le dégradé d'une barre est à l'enversClique sur ⇄ sur cette barre
Une barre est à moitié d'une couleur, à moitié d'une autreLe nombre de LEDs de la barre précédente est faux
Rien ne s'allumeVoir Dépannage

Les boutons Rouge, Vert, Bleu et Blanc allument tout de la même couleur. Ils servent à vérifier l'ordre des couleurs (RGB / GRB) réglé dans WLED et l'alimentation.

11. Enregistrer une disposition

Tous les réglages et la disposition sont mémorisés automatiquement dans le navigateur.

Pour garder plusieurs installations ou faire une sauvegarde : « 💾 Enregistrer la disposition » télécharge un fichier disposition-leds.json. « 📂 Charger une disposition » le relit.

12. Débit et alimentation

Combien de LEDs sur un seul fil ?

Une LED WS2812 met 30 µs à recevoir sa couleur. Avec 600 LEDs sur une broche, il faut environ 18 ms par image, soit environ 54 images/s au maximum. 30 images/s passent donc largement. L'application affiche ce calcul dans le bloc « WLED / Art-Net ». Au-delà de 800 à 1000 LEDs par broche, il vaut mieux répartir sur plusieurs sorties.

Alimentation

  • Une LED en blanc à fond consomme environ 60 mA. 600 LEDs en 5 V, c'est jusqu'à 36 A.
  • Réinjecte l'alimentation (+ et −) à plusieurs endroits, par exemple à chaque barre. Sinon le bout des barres tire vers l'orange et scintille.
  • Règle Maximum current dans WLED pour ne jamais dépasser ton alimentation.

13. Dépannage

ProblèmeSolution
« Relais : injoignable »La fenêtre noire de lancer.bat est fermée ou n'a pas démarré. Relance-la. Si Python est introuvable, réinstalle-le en cochant « Add python.exe to PATH ».
« Relais : connecté » mais LEDs éteintesVérifie l'IP (WLED doit s'ouvrir sur http://192.168.50.2), le type Art-Net et l'univers de départ dans WLED. Vérifie aussi que le pare-feu Windows autorise Python.
Seule une partie des LEDs s'allumeLe nombre de LEDs dans WLED (LED Preferences) est trop petit, ou l'univers de départ ne correspond pas.
Image mélangée, barres dans le désordreDésactive la 2D dans WLED, puis vérifie avec la mire.
Couleurs inversées (rouge à la place du vert)Change l'ordre des couleurs (GRB / RGB) dans WLED → LED Preferences.
Image saccadéeGarde la page visible, baisse « Images / seconde » à 25, ferme les autres onglets lourds.
Port 8080 déjà utiliséLe relais tourne déjà dans une autre fenêtre : ferme-la ou utilise-la.
Écran noir lors de la captureCertains sites protégés (Netflix…) bloquent la capture. YouTube fonctionne.
